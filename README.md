# Kali AI Control Center

A **policy-based Cyber Operations GUI** for Kali Linux that combines
tool orchestration, guided exploitation, AI-assisted analysis,
and forensic-ready reporting — all in one platform.

---

## ✨ Features

- 🧠 Natural language control for Kali tools
- 🔍 Network scanning (Nmap integration)
- 🔐 SSH & Tor log analysis
- 🛡️ Permission & safety policy engine
- 🧭 Guided Metasploit mode (human-in-the-loop)
- 🤖 AI-assisted summaries (offline fallback)
- 🧾 Court / client-ready PDF case reports
- 📦 Portable & Debian (.deb) packaging
