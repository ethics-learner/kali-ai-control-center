# Security Policy

## Supported Versions

The following versions of **Kali AI Control Center** are currently supported
with security updates:

| Version | Supported |
|--------|-----------|
| v1.0.x | ✅ Yes     |
| < 1.0  | ❌ No      |

---

## Reporting a Vulnerability

If you discover a security vulnerability, **please do NOT open a public issue**.

Instead, report it responsibly using one of the following methods:

### 🔐 Preferred Method (GitHub)
- Use **GitHub Security Advisories** (Private Vulnerability Reporting)
- Go to the repository → Security → Report a vulnerability

### 📧 Alternative
- Email: **ethicslearner@gmail.com**
- Subject: `Security Vulnerability Report – Kali AI Control Center`

Please include:
- A detailed description of the issue
- Steps to reproduce
- Potential impact
- Proof-of-concept (if available)

---

## Responsible Disclosure

We aim to:
- Acknowledge reports within **72 hours**
- Assess and validate the issue
- Release a fix in a timely manner
- Credit the reporter (if desired)

---

## Scope

This policy applies only to:
- Source code in this repository
- Official release binaries

It does NOT apply to:
- Misuse of the tool
- Unauthorized testing
- Third-party tools invoked by the platform (e.g., Nmap, Metasploit)

---

Thank you for helping make this project more secure.
